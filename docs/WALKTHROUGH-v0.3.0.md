## 三、统一加载/空/错误/超时（G10 机制）

- **加载**：全站 `SkeletonBlock` 分块骨架 + 1.4s 流光，禁白屏禁整页转圈（tokens.css 登记，reduced-motion 降级）。
- **空态**：全站 `EmptyState`（虚线框+星云晕染+一句话引导+主行动按钮），各页口径见 F3–F11 卡（如 P6 空态=仅官方套件+新建入口；P7 草稿=槽位待填充计数）。
- **错误**：`BannerAlert` 三级（红/琥珀/青），行内错误条（P6 安装拒绝、P7 拒绝激活）；不静默铁律 L9.2——失败必出事件/红条（P7 412、P9 需介入红框）。
- **超时**：P3 expired 虚框卡（F5.7）；P6 意识建议 >10s「分析中」可关闭（F8.4）；P7 校验失败显式呈现（L9.2）；事件检索 3s 降级（E1.6，B2 测试锁定）。
